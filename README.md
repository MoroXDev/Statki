Przebieg gry:

Gra przebiega w konsoli gdzie należy poustawiać swoje statki w wyznaczonym polu gry.
Następujące statki:
1x4 masztowiec,
2x3 masztowiec,
3x2 masztowiec,
4x1 masztowiec,

Zasady gry:

Zasady gry: Gra przebiega z komputerem lub drugim graczem, gra się kończy po zestrzeleniu wszystkich 
statków przeciwknika po czym następuję podliczenie statystyk gry zawierających: liczbę zniszczonych statków na liczbę trafień,
liczbę nietrafionych strzałów, liczbę tur oraz informację o wygranej lub przegranej.
